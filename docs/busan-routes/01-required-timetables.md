## 0. 읽는 법

**신뢰도 등급**

| 등급 | 뜻 |
|---|---|
| A | 공식 API 실응답(울산 BIS, TAGO). 당일 수집값 |
| B | 공식 API 값이지만 공식 게시 시간표와 교차 확인하지 않음(동해선, 1호선) |

| D | 비공식 출처 또는 표본이 적음(n<4) |
| E | 가정값 |

**통계 표기**
- 표기 형식: `중앙값 (p10~p90, n)`, 단위는 분입니다.
- 백분위: `statistics.quantiles(method="inclusive")`
- 요일구분: 평일=0, 토=1, 일·공휴일=2. 표본 기간의 공휴일은 2026-05-05, 05-25입니다.
- 시간대: 기점 시간표 출발 시각 기준 7구간(05–07, 07–09, 09–12, 12–16, 16–19, 19–21, 21–24)

**연결 계산표**
- 모든 연결 계산표는 **참고 계산**이고 화면에 그대로 쓰지 않습니다. 화면 적용 여부는 `02-plan.md` §3.2 규칙 U와 B-D10에 따릅니다.
- 판정식: `앞 구간 p90 + 환승 여유 ≤ 다음 편 승차(시간표 시각, 추정이면 p10)`
