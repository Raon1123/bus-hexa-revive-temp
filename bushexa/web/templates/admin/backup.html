가져오기 (Import/복구)

이전에 내보낸 ZIP 번들을 업로드해 설정을 복구합니다.
복구 전에 포함된 파일 목록을 미리 확인할 수 있습니다.
주의: 기존 파일이 덮어쓰기됩니다.

보안: 화이트리스트 경로 외 파일, 절대경로, 경로 탐색(..) 등은 자동으로 거부됩니다. 모든 JSON 파일의 유효성이 검사된 후에만 복구가 진행됩니다.
